# 动画优化与消灭星星（2026-11-13）

## 交付顺序

先优化现有果园消消乐，再新增独立消灭星星入口。大厅保留三打一、果园消消乐，扩展为三个入口。H5 与微信小程序均可进入，三个游戏的成绩互不覆盖。

## 果园消消乐动画

- 交换：两枚水果沿真实格子间距滑动，非法交换滑回，保持原来的不扣步规则。
- 下落：引擎为每一目标格输出来源索引；幸存水果按实际空位距离移动，补入水果从盘面上方进入。未移动的水果保持静止。
- H5 使用 Web Animations，落地轻弹、碎片和连锁分数浮出；系统减少动态效果时跳过装饰和位移动画。
- 动画与逻辑分离：先结算保存稳定状态，再展示动作。动画时禁止重复操作，离开取消动画，回来直接显示已保存的稳定结果。
- 小程序同步交换、退回和按距离下落动画。

## 消灭星星规则（本项目实现）

- 10×10 棋盘，5 色星星。点击横竖相连的至少 2 颗同色星星消除；斜向不相连。
- 一次消除 n 颗，得分 5×n²。星星下落，空列左移，不补新星星。
- 不限时间、不限步数。没有可消除组合后结算，再判断是否通关。
- 剩余 r 颗的额外奖励为 max(0, 2000−20×r²)，清空奖励 2000 分，只结算一次。
- 第 L 关累计目标为 1000+(L−1)×2000 分；得分带入下一关，最高支持 1000 关。
- 重玩本关重新生成盘面，分数回到进入本关时；历史最高分保留。
- 提示标出当前最大组。棋盘、入关分数、累计分数、终局奖励、最高分保存在 `popstar:progress:v1`，独立于其他游戏，无云排行榜。
